# キミの一歩、未来の地図。 — 更新版 v2

## 起動
`index.html` を VS Code の Live Server で開きます。GitHub Pages ではリポジトリ直下の `index.html` を公開してください。

## 今回の更新
- ホーム画面の人物を絵文字からピクセル単位のSVGドット絵に変更しました（外部画像不要）。
- 13〜22歳は毎年異なる目標・活動、大学院進学時の23〜24歳も毎年異なる内容にしました。
- 社会人以降は10年ごとに異なる目標・活動へ切り替わります。
- 勉強、運動、休息などの継続的な活動も、年齢によって説明・時間・ポイントが変わります。
- 既存のブラウザ内セーブデータを原則引き継ぎます。

## ゲーム内容を編集する
`game.js` 冒頭の `STAGES` に、各ライフステージの `acts` と `goals` をまとめています。

活動：`[ID, 名前, 説明, 消費時間, 努力ポイント, 自信ポイント]`

目標：`[ID, アイコン, 名前, 説明, 必要努力ポイント, 必要自信ポイント]`

活動IDのアイコンは `BASE_ACTS` で設定します。ポイントは10刻みで調整できます。

**注意**：ゲームバランスは暫定です。努力・自信は累積され、目標を選んでも消費されません。ステージ内の活動は何度でも行えます。

## 公開
GitHub リポジトリに `index.html`, `style.css`, `game.js` をアップロードし、Settings → Pages → Deploy from a branch を設定してください。

## セーブ
ブラウザの localStorage を使用します。以前のセーブを初期化する場合は画面右上の「最初から」を押してください。
